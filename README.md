# Expense Tracker – Phase 1 (Static UI)

React + Vite static UI. No state, no events, no API – hardcoded data passed through props.

```bash
npm install
npm run dev
```

## Component tree

```
App
├── Header
├── SummaryCard ×3 (Income, Expense, Balance)
├── TransactionForm
├── TransactionList
│   ├── FilterBar
│   └── TransactionItem ×6
└── Footer
```
